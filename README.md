# 产品 UI 设计与审美评审 / Product UI Design and Visual Review

`product-ui-design` · v2.2.1 · [GitHub Releases](https://github.com/simple0926/product-ui-design/releases) · [发行说明 / Release notes](RELEASE_NOTES.md)

## 中文

从需求和页面规格推导 UI 设计方向，并用实际画面与任务证据评审。

适用于 Web、移动和桌面产品的新设计、改版与实屏评审。结合产品价值、视觉方向、交互反馈、可访问性和平台约束。

1. 从 [GitHub Releases](https://github.com/simple0926/product-ui-design/releases/tag/v2.2.1) 的附件下载 `product-ui-design-v2.2.1.zip`。
2. 解压后把 `product-ui-design/` 文件夹复制到 `~/.codex/skills/`。更新前先备份你自行改过的文件。
3. 在 Codex 里输入 `$product-ui-design`，附上你的目标、已有材料和交付要求。

实验手册需在实际项目中运行，按目标平台、设备和操作证据验收。

## English

Develops UI directions from requirements and screen specs, then reviews them with screenshots and task evidence.

Use for new design, redesign, and real-screen reviews across web, mobile, and desktop. It connects product intent, visual direction, feedback, accessibility, and platform constraints.

1. Download the attached `product-ui-design-v2.2.1.zip` from [GitHub Releases](https://github.com/simple0926/product-ui-design/releases/tag/v2.2.1).
2. Extract and copy the `product-ui-design/` folder to `~/.codex/skills/`. Back up any local customizations before updating.
3. In Codex, invoke `$product-ui-design` with your goal, available inputs, and expected deliverables.

Run the protocol in real projects and verify the results on the target platform and device.
