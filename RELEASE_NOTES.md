# 产品 UI 设计与审美评审 / Product UI Design and Visual Review v2.2.1

## 中文

移动端包含 Apple HIG 试行规则、按平台检查表和对照实验方案。保持真实任务和内容一致，比较三个独立方向并记录实测差异。

实验手册需在实际项目中运行，按目标平台、设备和操作证据验收。

请选择 Release 附件里的 `product-ui-design-v2.2.1.zip` 安装。

## English

Mobile guidance includes trial Apple HIG rules, platform checklists, and a comparison protocol. Compare three independent directions using the same real task and content, and record observed differences.

Run the protocol in real projects and verify the results on the target platform and device.

Install using the attached `product-ui-design-v2.2.1.zip` from the release.
